领袖镇压不住夺舍人的补救及陷阱：领袖临终前，继任者在红南房的建议下，选择保留领袖肉身，红南房称这种方法可以凭借开国紫气压制部分夺舍人。其实红南房有自己的计划，即使“血咒”在百年之约到来之前不能逼出大祭司出世，那么最晚百年后，北房必定现身，这时候“北房”可能会面临一个问题，本应受封为王的领袖尸身仍在，一具空壳是否可封王？若是空壳肉体内寄居的是另外一个意识呢？这个手段其实是红南方和蓝南房的合谋，蓝南方在不断探索意识存在的不同方式和载体，例如近些年的人形机器人，AI智能体等等。包括区块链技术的发展，背后都有蓝南房在背后的支持。蓝南房已经逐渐发展成追求人人平等，人人都有足够智慧，意识可以脱离于肉体存在得到永生，追求绝对公平的的组织。部分蓝南房的核心成员正在进行人类意识剥离试验。

“北房”的恐怖之处：北房除了能给当世强者封王盖章，让强者拥有压制人世间的精怪之外，还有一个很隐蔽的能力，就是制定规则，选择人世间的某些人，赋予异能、法力，或者一段意识，改变历史走向。换句话说：人世间，人人都有可能是“北房”选中人。例如崇祯皇帝身边的太监王承恩，推动了崇祯上吊的行动；元朝末年协助**王保保渡黄河，让北元力量得到保存；陆秀夫背着少帝赵昺跳海，结束了宋朝；燕王朱棣避开朱允炆主力直接攻打南京，结束了朱允炆的统治；铁木真幼时逃亡得到锁儿罕失剌帮助等等背后都有参与。**  “北房”历代的核心一直在做的一件事，就是不断修补历朝历代的漏洞。
